# Dynamic Text Preview

Meu primeiro projeto utilizando HTML, Tailwind CSS e JavaScript.

A ideia é simples: digitar um texto e visualizar as alterações em tempo real, além de poder mudar a cor do texto através de botões.

## O que pratiquei

- Manipulação de DOM
- Eventos com JavaScript
- Funções e parâmetros
- Tailwind CSS
- Organização de arquivos

## Tecnologias

- HTML
- Tailwind CSS
- JavaScript
